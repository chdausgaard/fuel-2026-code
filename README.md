# Fuel-cost burden and the 2026 U.S. midterms: analysis code

The analysis code of a pre-registered study by Christoffer H. Dausgaard (University of Copenhagen). It is the code named in section 11 of the registration: the models, the reports, the treatment build, and the analysis and window settings and the frozen group lists.

This is a copy made from a list of named files. It holds no data, so it does not run on its own.

The local gasoline prices are daily AAA averages, as archived by public third-party scrapers and the Internet Archive. I do not redistribute them. AAA did not take part in this work or endorse it.
